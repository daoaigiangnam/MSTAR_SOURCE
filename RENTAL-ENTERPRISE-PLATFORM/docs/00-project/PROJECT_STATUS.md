## Working Model
- GitHub `main` is the stable project baseline.
- Approved decisions and requirements must be recorded in `docs/`.
- Every feature follows: Requirement → Analysis → Design → Implementation → Test Case → Test Result → UAT → Freeze → Release.
- A feature is not considered complete merely because code works.
