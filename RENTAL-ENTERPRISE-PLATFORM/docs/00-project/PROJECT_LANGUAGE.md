## Trạng thái

## Quy ước
- Trao đổi, phân tích nghiệp vụ và tài liệu dự án sử dụng tiếng Việt.
- Tên module, class, API, database table/column, biến và mã nguồn sử dụng tiếng Anh theo chuẩn kỹ thuật.
- Thuật ngữ kỹ thuật phổ biến có thể ghi tiếng Anh kèm giải thích tiếng Việt khi cần.
- Nội dung kiểm thử, Test Case và Test Result ưu tiên tiếng Việt.

## Mục tiêu
Bảo đảm người dùng và đội phát triển đọc tài liệu thống nhất, đồng thời giữ code và technical identifier dễ bảo trì, tích hợp và mở rộng.
