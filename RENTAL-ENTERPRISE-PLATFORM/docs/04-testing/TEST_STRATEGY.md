# Test Strategy

## Objective
Verify that approved requirements are correctly implemented, secure, reliable, and regression-safe.

## Test Levels
- Unit Test
- Integration Test
- API Test
- Contract Test
- Database / Migration Test
- UI Test
- Mobile Test
- Security Test
- Performance Test
- Regression Test
- User Acceptance Test (UAT)

## Evidence
Test cases and execution results must be stored in the repository or linked to immutable build/test evidence.

## Completion Rule
A feature cannot be marked FROZEN solely because automated tests pass. Applicable manual, integration, security, regression, and UAT evidence must also be satisfied according to the feature's risk profile.

## Defect Lifecycle
OPEN → TRIAGED → IN PROGRESS → FIXED → RETEST → VERIFIED → CLOSED
