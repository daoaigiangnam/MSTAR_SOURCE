# Enterprise Roadmap

## Phase 0 — Foundation
IAM, organization, tenant isolation, security baseline, audit, API conventions, CI/CD and project skeleton.

## Phase 1 — Property Core
Portfolio, property, site, building, block, floor, unit type, unit, tenant and lease foundation.

## Phase 2 — Financial Core
Meter, pricing, billing, invoice, payment, deposit, AR/collections and expense/AP.

## Phase 3 — Operations
Maintenance, work order, asset, vendor, inventory and inspection.

## Phase 4 — Experience
Tenant mobile app, owner/manager mobile workflows, web portal, document management and notification center.

## Phase 5 — Platform
Workflow engine, integrations, public/partner API, webhooks and event platform.

## Phase 6 — Intelligence
Analytics, data platform, OCR, AI assistant, forecasting and anomaly detection.

## Phase 7 — Marketplace
Listings, search, map, booking, viewing and tenant/property matching.

## Delivery gate for every module

Analysis → Domain design → Database/API design → Implementation → Unit tests → Integration tests → Security review → UAT → Freeze.
