# Chỉ mục tài liệu ITSM — MSTAR Corp

> **QUY ƯỚC MỘT NGUỒN CHÍNH THỨC:** Thư mục `docs/procedures/` là nơi duy nhất chứa các quy trình vận hành chi tiết ITSM-INC-001 đến ITSM-DOC-001. Thư mục `docs/itsm/` chỉ chứa sổ tay/quy chế, lưu đồ tổng thể, bảng SLA nguồn, bộ biểu mẫu, kiểm soát hồ sơ, đối chiếu ISO, đánh giá và CAPA; các tài liệu trong đó không thay thế hoặc tạo ra một phiên bản quy trình vận hành thứ hai. Khi nội dung khác nhau, phải rà soát và cập nhật quy trình chuẩn tại `docs/procedures/`, sau đó cập nhật link/tài liệu tham chiếu liên quan. Tất cả vẫn là DỰ THẢO cho đến khi được phê duyệt.
