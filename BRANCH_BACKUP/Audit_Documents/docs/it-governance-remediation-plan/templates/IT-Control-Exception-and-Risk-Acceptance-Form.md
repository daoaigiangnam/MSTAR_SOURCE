## 1. Rule of use

Use this form when a required control cannot currently be met or a temporary exception is requested. An exception is not automatic permission to bypass policy. Do not use this form to retrospectively legitimize an unapproved action. Record any existing non-compliance honestly and begin containment where necessary.
