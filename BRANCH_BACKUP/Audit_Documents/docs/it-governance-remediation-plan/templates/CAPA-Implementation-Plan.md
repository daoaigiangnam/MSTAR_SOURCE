## 1. Purpose and instructions

Use one plan per audit finding or control deficiency. Link it to the approved finding/CAPA register. This template records actions and evidence; it does not itself confirm that a finding is valid or closed.

Do not backdate actions or approvals. Distinguish reported concerns, facts verified by evidence, hypotheses, and items awaiting validation. Store sensitive evidence in the approved restricted repository and record only its evidence ID/link here.

## 4. Milestones and acceptance criteria

For each action, define observable acceptance criteria before implementation. Examples include an approved procedure, a complete authorization record, an access review with exceptions resolved, or a witnessed restore test. Avoid criteria such as “staff informed” unless attendance/acknowledgement and a control test are also defined.
