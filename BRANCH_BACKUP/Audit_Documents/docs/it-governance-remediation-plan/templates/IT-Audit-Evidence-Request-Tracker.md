## 2. Request quality checklist

Before sending a request:
- [ ] State the audit/control objective and related finding ID, if any.
- [ ] Identify the exact system, process, population and period.
- [ ] Specify the source of record and expected fields/format.
- [ ] Name the evidence owner and authorized approver for disclosure.
- [ ] Set a realistic due date and secure delivery channel.
- [ ] Request original timestamps/metadata where relevant.
- [ ] Explain required redaction and classification.
- [ ] Avoid requesting passwords, tokens, private keys, or unnecessary personal data.

## 3. Validation checklist

When evidence arrives:
- [ ] Record source, version, collector, receipt date and evidence ID.
- [ ] Preserve original evidence where permitted; analyze a controlled copy.
- [ ] Confirm period, population, completeness and source provenance.
- [ ] Confirm evidence supports the stated criterion—not just that a procedure exists.
- [ ] Record missing fields, exclusions, conflicting evidence and limitations.
- [ ] Link evidence to test records, findings and CAPA.
- [ ] Obtain independent review for high-risk or closure evidence.
- [ ] Restrict access and log any external/auditor handover.

## 4. Escalation

For overdue or unavailable evidence, record the reason, responsible owner, impact on audit assurance, interim measure, revised due date, and escalation decision. Do not fabricate records, backdate approvals, or mark a finding closed solely because evidence was requested.
